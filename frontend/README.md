# Kanban Frontend

Next.js 15 (App Router) + React 19 + Tailwind CSS v4 client for the Mini Kanban Board.

See the [repository root README](../README.md) for full setup instructions (Docker and manual), environment variables, and an overview of how this talks to the backend.

## Quick reference

```bash
npm install
cp .env.example .env.local   # set NEXT_PUBLIC_API_URL
npm run dev                  # http://localhost:3000
```
